# Design System & UI Tokens: ANLEYLAB Bible

##    Color Palette (HSL Engineered)
*   Primary (Brand & CTAs): #0F4C81 (Deep Liturgical Blue)
*   Secondary (Accents): #C8A951 (Warm Liturgical Gold)
*   Background: #FAFAFA (Off-White, anti-glare foundation)
*   Surface: #FFFFFF (Pure white for cards/dialogs)
*   Text (Primary): #14191F (Deep slate gray instead of harsh pure black)

##     Layout & Atoms (4dp/8dp Soft Grid)
*   Screen Margins: 20dp or 24dp padding on outer left/right edges.
*   Component Spacing: Strictly increments of 4 (4dp, 8dp, 12dp, 16dp, 24dp, 32dp).
*   Border Radius: 12dp for standard cards, 20dp for main action elements.
*   Typography Base: 16sp minimum for scripture body text to ensure legibility.
*   Accessibility Touch Targets: Minimum 44dp × 44dp for all buttons/icons.
*   Animations: 250ms ease-in-out curve for all state transitions.
